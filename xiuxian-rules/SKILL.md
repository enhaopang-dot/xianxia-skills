# 修仙规则数值库

## 何时使用

- 设计修仙/玄幻游戏的数值体系（直接以 rules.json 为起点调参）
- **校验 LLM 生成的修仙内容**：LLM 写境界、寿元、突破、战斗结果时，必须对照本库锚定，防幻觉
- 评审修仙设定合理性（小说剧本/世界观文档）

## 数据位置

`D:/Claude/配置/.claude/skills/xiuxian-rules/rules.json`（JSON，程序可直接读取）

## 核心口径速查

| 维度 | 基准 |
|---|---|
| 大境界 | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，各四小阶（前/中/后/圆满） |
| 寿元 | 凡人80 / 练气100 / 筑基150 / 金丹250 / 元婴500 / 化神1000 / 之后翻倍 |
| 灵根 | 天灵根(单)1.0 → 伪灵根(五)0.12；变异灵根 1.1；分布越好的越稀有 |
| 大境界突破 | 练气→筑基 40% 起，逐级腰斩，大乘→渡劫仅 0.5%；加成上限 +30pt，clamp [1%, 95%] |
| 境界压制 | 差 1 大境：伤害 ×1.5 / 受击 ×0.6 |
| 品阶 | 白绿蓝紫金 = 1.0/1.3/1.7/2.3/3.0 效果系数，权重 15/35/25/12/8 |
| 心魔 | 每点 -5pt 突破概率、+20% 天劫强度 |

## 使用原则

1. **锚定而非死板**：数值是基准线，具体项目可调，但调整必须全表联动（改了寿元就要改突破概率，否则世界人口结构崩坏）
2. **喂给 LLM 的规则**：让 LLM 生成修仙内容时，把相关段落塞进 prompt 作为「世界规则约束」，并要求输出违反时自我修正
3. **校验清单**：修仙内容交付前过一遍——寿元超没超？境界压制对不对？突破说成就成（概率口径去哪了）？
4. 本库数值为原创基准，综合修仙网文通用口径，不绑定任何特定作品
