# LLM 世界模拟架构

## 何时使用

- 设计 LLM 驱动的世界模拟/NPC 社会/涌现叙事系统
- 审查此类系统的架构方案（对照清单逐项过）

## 一、最高信条：代码管事实，LLM 管文采，永远分层

1. 先由代码完成业务结算并生成**事实事件**，LLM 只在事实之上追加**叙事扩展层**
2. LLM 永远不碰状态：它的产出必须过校验层（draft→校验→一次性 apply）
3. 给 LLM 的上下文永远「风味名+标准 ID」双发，prompt 明令参数只许用 ID
4. LLM 批处理任务最强约束范式：**输入 N 个必须输出 N 个、ID 完全保留**、禁机制文本；失败 chunk 用规则 fallback 补齐

## 二、五条工程铁律

1. **真源唯一，推导为奴**：任何数据只存一份，其余全是推导/缓存；显示名、索引、视图绝不入档
2. **单一写通道**：所有写操作（模拟步进/玩家输入/LLM 回调）过同一串行入口；异步回调只许 enqueue，禁止直写
3. **持久化只存 ID**：跨对象引用只存稳定 ID（枚举/GUID），读档统一按 ID 重绑定；找不到定义报错而非静默置空
4. **运行时状态与世界状态分家**：会话/待决请求/冷却纯运行时，不进存档，读档即清
5. **声明式边界**：行为策略（能否被打扰/效果合法形态/决策任务结构）注册为声明，新增扩展=新增声明而非修改他人代码；未知类型**失败封闭**

## 三、决策网关（单机商业产品的命脉）

- 所有 LLM 调用收敛到**一个带 task_name 的网关入口**：并发限流/失败降级/成本统计/日志/测试拦截全在这一个截面解决
- task_name 注册表：每个决策任务有确定返回结构；未注册任务抛异常
- **三种可替换实现**：真实 LLM / 规则 fallback（返回消费方能解析的**合法值**，不是空字典）/ 受控拒绝
- **无 LLM 完整可玩**：玩家没配 Key 时游戏不死（规则模式）；Editor 下跑「零 LLM 全模拟」集成测试
- **分级调用**：深度档（重大决策/剧情扩写）+ 日常档（即时反应），按任务配模型档位——成本命脉
- **决策频次按 NPC 重要度分层**：主角级全量 / 配角级抽样 / 龙套级纯规则+预写模板（背景板 NPC 零 LLM 成本：无名画像×预写事件×标签过滤，只写余波不解释真相）

## 四、信息三层可见性（叙事引擎）

| 层 | 原则 |
|---|---|
| 玩家（上帝视角） | 全公开 |
| 事件流 | 不透题：只报迹象不报名称坐标 |
| AI 上下文 | **只喂角色实际知道的信息**——连标题都不给（标题即剧透） |

秘密/机缘类系统的配方：**结构化内部状态 + 给 AI 的只有模糊自然语言感应**（严禁目标 ID/建议动作/风险提示），限时状态机+命中检测+冷却。

## 五、玩家介入 = 可插拔决策源

- 玩家抽象为与 LLM、规则 fallback 并列的 `DecisionSource`；业务层只声明「这里需要一个决策」，**禁止 `if 玩家` 分支**
- 接管只发生在**决策边界**（动作链执行完、需要新决策时），绝不在动作中途打断
- 自由对话必须挂在正式世界动作上；高膨胀内容（对话原文）压缩成摘要才准入库

## 六、记忆与叙事

- 记忆即事件流，按重要性分级：major 进长期 / 普通进短期 / story 是叙事正文层，三层标记共存
- 月度数值快照（不可变、只增、定长裁剪）——编年史/复盘的数据地基，成本极低
- 故事收口：所有小故事调用统一服务，按类型集中配概率；高频机械动作禁止接入（防事件栏刷屏）

## 七、架构审查清单

审查一个 LLM 模拟系统方案时逐项过：

- [ ] LLM 能直接改世界状态吗？（能→🔴 必须有校验层）
- [ ] 存在两份平行真源吗？（存在→🟡 未来必不一致）
- [ ] 异步回调能直写状态吗？（能→🔴 随机坏档）
- [ ] 无 Key/无网时游戏能跑吗？（不能→🔴 商业死局）
- [ ] 决策调用有单点网关吗？成本可观测吗？
- [ ] NPC 知道它不该知道的信息吗？（AI 上下文洁癖）
- [ ] 有非目标清单吗？（没有→🟡 复杂度预算失控）
- [ ] 戏剧张力可度量吗？（单位时间 major 事件数，低于阈值有自动扰动吗）
